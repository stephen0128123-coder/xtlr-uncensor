# 构建与验证说明

本版本使用国服2.0.2/RES2611061353与日服2.0.2/RES2611061340资源。这里只说明已完成的离线检查及其边界，不把它们等同于游戏内实测。

## 资源来源和改动

128个目标中125个与v2.1.0逐字节相同，官方基准未变；三个变化的icon基于最新官方目标制作。官方基底由公开BSDIFF40差分离线重建，最终MD5及大小与官方清单目标一致。

只替换25张满足同尺寸、格式、mip和字节长度条件的美术纹理原始字节，保留国服对象、路径、引用和非目标内容。发行清单的post MD5来自最终实际文件，不从旧台账估算。

## 已完成检查

- 128个最终资源实际回读并核对MD5/SHA256/大小；125个复用项与旧版相同。
- 三个重建icon的全部解压节点、3307个序列化对象及非目标字节检查通过，三张新增国服语言纹理保留。
- 独立纹理来源与Live2D成套内容检查通过；已知尺寸/路径例外见README和故障排查，未将其冒称全部恢复。
- 17项资源测试及独立负向检查通过，覆盖层错、清单错误、目标外字节变化、来源绑定、长度和路径等情况。
- 安装/卸载脚本在隔离模拟目录中完成194项测试断言及280项独立断言检查，并验证Windows PowerShell5.1兼容性。模拟资源不是游戏，脚本测试不等于实际安装或游戏内测试。
- 公开包的资源及五个运行时脚本与已审核版本保持一致，清单和元数据原始字节保持一致；ZIP逐成员CRC/哈希/大小回读核对。

尚未完成v2.1.1在真实游戏中的全场景实测。离线检查不能保证所有动作、界面、账号或渠道兼容性，更不代表官方许可或零封禁风险。

本包仅含必要资源、安装/卸载脚本和文档，不含开发日志、账号信息、测试夹具或本机目录记录。ZIP完整文件SHA256放在发布页及独立校验文件，不放入ZIP自身以避免自引用。
