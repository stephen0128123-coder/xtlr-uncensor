# v2.1.1 更新记录

## 同版本安装器修订

- 参考旧版恢复注册表、常见安装位置及浅层搜索，正常不再要求拖入游戏目录；多个候选选编号，未找到才打开文件夹窗口。
- 修正PS/icon-0等因作者原件白名单产生的安装拦截：先精确备份现有文件，再替换；不再要求现有字节等于作者样本。
- 仍校验本包源完整性、有效且唯一GAME_VER及目标官方资源版本，拒绝损坏包或把旧资源盖到真正更新的游戏。
- 不因无关RES或整份清单SHA变化误拦；不跨层写入，不把旧备份跨版本还原。
- metadata/manifest和包ID不变，兼容原v2.1.1收据。美术128资源与前一份v2.1.1逐字节相同。
- 18组真实Windows PowerShell5.1模拟场景及独立代码复审通过，仍未验证报告该问题的玩家机器。
