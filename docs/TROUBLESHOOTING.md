# 故障排查 — v2.1.1

本版本，已做离线检查，尚未完成游戏内实测。先完整解压、完全退出游戏，并保存窗口原文。以下是核验说明，不是授权助手自行修复或写入游戏。

## 安装拒绝并不等于资源脏

| 提示/情形 | 含义与处理 |
|---|---|
| 游戏正在运行 | 脚本检测xtlr进程；玩家完全退出游戏后再决定是否操作。 |
| 包数据缺失、post校验失败 | 源文件不完整/被改；停止，不往游戏写。重新核对本版本ZIP和清单，不删IR。 |
| RES_VER/官方基准不符 | ss_win.mani整文件SHA或RES变化；不能用本包安装/还原。保留当前文件和备份，另核对新基准。即使无关字段变化也会保守拒绝。 |
| 当前目标未知 | 既不等于该行pre/post，也不在该PS目标显式acceptedPre内；不能强装。先只读核对具体层、路径、哈希与来源。 |
| post但无本包收据 | 可能他包安装/手工复制；本包不接管其恢复，不能伪造收据。 |
| 备份/收据错误 | 保留实际文件、状态目录和原包，停止自动恢复。不要删除证据后重试。 |

安装器先校验全部128源文件、元数据、显式目标及已有备份/收据，再进入目标写入；不补写另一层。预检失败时不会写入资源，但磁盘故障、外部改写或中断发生在写入阶段，仍可能出现部分已写：这不是全包原子事务。

## 三个旧官方PS兼容输入

[package.json](<../data/package.json>)只额外接受PS/icon-c,d,f的已证实旧官方哈希。它们干净但不等于最新清单目标；已存在的差分更新成功日志、版本索引与当前实物不一致原因未确定，不能说用户没更新或懒应用。

安装会备份真实安装前字节，记录MD5及SHA256；卸载恢复该原件。若装前是旧官方，卸载后仍是该旧官方；不会擅自升级/修复。不能把某包的acceptedPre用于其他包/层，也不能加入任意未知哈希。

## 新备份和恢复收据

状态在游戏目录的 `_xingta_switch/<RES与基准短名>/<包ID短名>/`，收据仍严格核对完整版本、包ID、基准和游戏路径。每个层/包单独备份，记录实际原件双哈希。旧 `_uncensor_backup_*` 与旧包都保留，新外壳不搜索或混用它们。

只恢复本包收据标记written的目标；当前post且备份校验通过才恢复，已等于实际backupMd5则幂等记录。未知字节、其他合法但非本次原件的版本、基准变化或损坏备份均不覆盖。

receipt.jsonl追加完整快照并校验最后一条。最后半条、空文件、坏JSON/校验不符直接失败，不回退到更早快照。pending+post表示写入确认中断：备份保留，安装/卸载自动失败关闭；不要盲目复制旧备份。恢复已经完成但收据未更新的情况可在校验一致时重跑卸载。本包不承诺异常断电自动回滚。

## 白块、卡面没变、动作异常

白块只是症状，不能由数量差或缺一条容器直接确定原因。只读核对该场景对应目标、实际层/MD5、资源路径、基准及源完整性，再结合截图和玩家实测。新内容未显示可能涉及版本新增素材，也可能是其他引用/加载原因；不直接断言新版落后或要求完整修复。

## 热更与反馈

计划更新前，基准仍适用时由玩家用原包正常卸载；更新后先核对新基准。已经更新而被本包拒绝恢复时，保留现状和备份，不旧备份覆盖、不删游戏、不默认完整修复。是否使用官方修复应在问题核清后由玩家决定，本报告不代为执行。

反馈最少提供：[game_version.txt](<../data/game_version.txt>)、游戏清单版本/SHA256、具体界面/角色/动作截图、安装/卸载窗口原文、相关目标层和MD5，以及必要的收据状态。不要发送账号、token或cookie。完整技术细节见[资源结构说明](<资源结构说明.md>)。
