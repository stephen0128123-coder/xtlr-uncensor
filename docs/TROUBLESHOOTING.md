# 故障排查

装完发现没效果、界面异常、报错，先按这份文档对一遍。

适用：模组 **v2.1.0** / 游戏 **2.0.1**

---

## 排查第一原则

**先确认三件事，八成问题到这就解决了：**

1. 游戏**完全退出**了吗（任务管理器里 `xtlr.exe` 没了）
2. 压缩包是**整个解压**的吗（`data` 文件夹和 `install.bat` 在同一层）
3. 游戏版本和模组版本对得上吗（看下面的表格）

| 模组版本 | 适配游戏版本 |
|---|---|
| v2.1.0 | 2.0.1 |
| v2.0.2 / v2.0.1 / v2.0 | 2.0.0 |

---

## 一、安装阶段的报错

### 「游戏正在运行」

游戏没退干净。任务管理器 → 详细信息 → 找 `xtlr.exe` → 结束任务。

注意：启动器在后台跑也会拦。

### 「这个文件夹不完整 / 安装包缺 N 个文件」

解压不完整。

```
1. 关掉窗口
2. 右键压缩包 →「解压到当前文件夹」← 不要双击压缩包里的 install.bat
3. 进解压出来的文件夹，双击 install.bat
```

判断对不对：`data` 文件夹要和 `install.bat` 在同一层。

如果反复缺文件，检查杀毒软件隔离区。

### 「磁盘空间不足」

替换过程需要约 1.2 GB 临时空间。

### 「写入校验失败 / 有 N 个包失败」

某个包写进去后 md5 对不上。可能是：

- 杀毒软件实时扫描锁住文件
- 权限不足（游戏装在 C 盘常见）
- 硬盘问题

处理顺序：

```
1. 关掉杀毒软件实时防护，重装
2. 右键 install.bat →「以管理员身份运行」
3. 还是不行，把游戏移到非系统盘
```

### 「没找到备份目录」

之前没用这个包装过，或者备份目录被删了。

处理：用启动器的「**完整修复**」代替卸载。

## 二、装完了但界面异常

### 白块 / 图标空白 / 图片不见了

白块 = 游戏要某个资源，包里没有。

**先做这一件事**：判断白块出现在哪类界面。

| 白块位置 | 大概率原因 | 怎么办 |
|---|---|---|
| **新角色 / 新皮肤 / 新活动** | 模组版本落后，那个包里没有新素材 | 等新版模组 |
| 商店、物品、旅人列表、秘纹列表 | icon 包层写错 | 卸载 + 完整修复 + 重装 |
| 角色立绘、卡图 | 对应角色包没装对 | 同上 |
| 整个界面都白 | UI 包被误改 | 同上 |

**如果是「新内容」白块**，那就是这个模组跟不上游戏进度了，装多少次都没用，得等我更新。

**如果是「老内容」白块**，按这个流程修：

```
1. 双击 uninstall.bat          ← 退回国服原版
2. 启动器 →「完整修复」 → 等它跑完
3. 双击 install.bat            ← 重新装
```

### 旅人列表 / 秘纹列表的卡图没变

卡图在 icon 包里。其他内容换了但卡图没换 = icon 包没装对。

检查 `data/manifest.tsv` 里 `icon-*` 那 16 行的「层」字段，应该是 `PS`。

### 某个角色立绘没换

看这个角色在不在清单里：

- 立绘：`char_2d_<id>`
- 剧情立绘：`char_avg_2d_*`
- Live2D：`char_l2d_<id>`

**不在清单里 = 这个角色本来就没被和谐**，不需要换。

### 立绘遮罩异常（圣光 / 遮挡布）

日服把 `masktexture.asset` 从 Live2D 包里裁掉了，模组有 28 个 Live2D 包因此缺这个文件。

判断：一般不影像显示。但如果出现遮罩相关异常，这是第一个要怀疑的点。

反馈时说明是哪个角色、什么现象。

### 界面文字变成日文

不应该发生。替换范围排除了本地化资源。

如果出现了，说明装错了包，反馈时说明具体界面。

## 三、卸载相关

### 「没找到备份目录」

备份被删了，或者当时不是用这个包装的。

处理：用启动器的「完整修复」代替。

### 卸载后游戏还是不对

1. 确认游戏完全退出后再卸载
2. 启动器「完整修复」
3. 最坏情况：卸载游戏 → 删掉 `StellaSora_CN` 文件夹 → 重装

> 只删 `StellaSora_CN` 这一层，别删它的上级目录。

---

## 四、常规维护：游戏更新前先卸载

**这是最重要的一条。**

```
1. 双击 uninstall.bat        ← 先退回国服原版
2. 打开启动器，更新游戏
3. 再双击 install.bat        ← 装回模组
```

**顺序不能反。** 先更新再卸载，备份里的旧文件会盖到新版游戏上，问题更多。

---

## 五、反馈问题时请带上这些

能大幅加快定位：

1. **游戏版本**：`游戏目录\Persistent_Store\ss_win.mani` 里 `$RES_VER` 那一行
2. **模组版本**：`data\game_version.txt` 的内容
3. **具体现象**：哪个界面、哪个角色、截图
4. **是否装过旧版模组、是否中途更新过游戏**
5. **`install.bat` 的完整输出**（如果报错）

第 4 点特别重要。「装过旧版没卸载就更新游戏」是效果不一致的头号原因。

## 六、常见误解

**「装了没反应」**
先确认版本对不对。再看是不是被「完整修复」还原回去了。

**「上次能用这次不能」**
游戏更新了，模组跟不上。

**「别人能用我不能」**
环境不同。检查游戏是不是装在 C 盘、是不是装过别的小开关。

**「重装模组就行了吧」**
如果游戏目录本身已经脏了（有别的模组残留），光重装没用，要先退回国服原版。

**「白块是不是模组坏了」**
不一定。新内容白块是版本落后，不是坏了。
