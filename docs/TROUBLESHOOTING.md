# 遇到问题怎么办

## 安装找不到游戏

完整解压到游戏目录外，双击 install.bat。会先自动找国服；多个结果选编号，没有结果才选文件夹。不需要安装日服。

## 卸载

退出游戏和启动器更新任务，双击与安装时相同包里的 uninstall.bat。它按安装记录把原文件放回，不扫描其他资源、不做完整官方复验。

备份在 `%LOCALAPPDATA%\XingtaSwitch\`，不是游戏根目录。没有记录、备份缺失、文件被占用或没有写权限，都会直接报错；保留窗口的原话和备份排查，不靠重装游戏、关安全防护来绕过。

本版不检查备份内容是否在保存后被外部损坏，所以请勿改动备份。文件写入过程发生错误时也不能假装完成；外置记录会保留，便于继续恢复。

## 更新顺序

先卸载小开关，再更新游戏。新版卸载按记录直接放回原文件，不负责识别更新后的官方版本；已经更新过就不要直接运行旧包卸载，以免覆盖更新内容。

## 根目录里还有旧小开关文件夹

本包不在游戏内创建备份或临时目录，也不会擅自删除其他版本留下的 `_xingta_switch` 或 `_uncensor_backup*`。那些目录可能是唯一旧备份，请先记录实际路径、来源和版本再单独处理。不能按名字整目录删除。

## 白图、立绘或动画异常

先记下具体角色、页面和原始错误。已知资源例外见[资源结构说明](资源结构说明.md)。离线或模拟测试不等于游戏内通过；不要直接整包移植日服 icon，也不要把补丁层文件覆盖到基础层。
