# 故障排查 — v2.1.1 安装器修订

## 以前报“目标不是本次允许的官方原件或本包内容”

这是旧安装器将作者样本原件哈希当作玩家现有文件准入条件导致的拦截。目录通常已经找到了，不是拖入动作本身失败。请重新下载本次同名完整包，不要把旧tools混入。

本修订不再按该白名单拒装：先备份玩家当前文件，再替换为本包内容。仅凭当前文件第三种MD5不能断言游戏损坏或让玩家重装。备份只还原实际安装前内容，不保证它就是官方原版。

## 自动定位

双击install.bat或uninstall.bat会自动寻找。单一候选直接使用；多个候选选编号；自动找不到时才弹文件夹窗口。请核对窗口显示的目录，尤其有多个副本、自定义深层路径时。缓存、注册表和常见位置优先，浅层搜索不是全盘唯一性证明。

## 仍会停止的情况

| 情况 | 处理 |
|---|---|
| 本包源文件缺失/post不符 | 整个重新解压安装包，不要在压缩包内直接运行。 |
| game_version.txt缺失、GAME_VER缺失/重复/无效 | 包不完整或配置异常，重新解压，不跳过版本检查。 |
| 游戏GAME_VER与适配版本不同 | 使用适配版本。 |
| 官方清单中的目标资源MD5已变化/目标不存在 | 该资源真正更新或未就绪，不能用旧包强盖，先核对更新情况。 |
| 已有备份与当前原件不一致、收据损坏 | 保留现状和备份，不删收据、不复用错误备份。 |
| 卸载时目标已被热更/他工具改变 | 不覆盖新内容；保留备份，核对当前版本和实际文件。 |
| 写入前后文件变化或权限错误 | 停止后保留窗口输出和备份，查占用/权限，不默认关闭安全防护。 |

无关RES、整个清单SHA变化而目标官方版本未变，不再直接阻止安装。仍只写128清单目标的指定层，不会把PS包复制到IR。

## 卸载与中断

用同一解压目录的uninstall.bat。备份/收据在游戏_xingta_switch内，保留文件夹；原v2.1.1包身份未变，既有收据仍可读取。未知或损坏备份、错误包/目录/层绑定不恢复，pending+post表示写入确认中断，也不盲目自动恢复。不承诺断电全包回滚。

游戏更新前先卸载。若已经热更，不用旧备份强盖新版本。新外壳不复用更旧_uncensor_backup_*目录。

## 已知美术例外

本次没有修改美术：icon-0/outfit_3019_a因尺寸不兼容保留CN；npc_l2d_917302的chat_e.anim/.fade.asset/.motion3.json为既有路径差异，未证实新增故障，待实际场景确认；四抽卡封面仍未纳入128目标。

出现白块请提供具体界面/角色/动作截图和窗口输出、版本及相关文件状态，不要仅凭缺路径或数量差直接归因，不要发送账号密码或登录凭证。
