# 故障排查

装完发现没效果、界面异常、报错，先按这份文档对一遍。

**排查第一原则：先跑 `tools\precheck.bat`。** 它会把环境问题指出来，比瞎猜快。

---

## 一、安装阶段的报错

### 「游戏正在运行（xtlr.exe）」

游戏没退干净。任务管理器 → 详细信息 → 找 `xtlr.exe` → 结束任务。

注意：有时候启动器还在后台跑，也要关掉。

### 「安装包缺 N 个资源文件」

解压不完整。常见原因：

- 压缩包没下全（比对一下文件大小）
- 解压软件中途报错
- 被杀毒软件拦截了部分文件

处理：重新解压。如果反复缺，检查杀毒软件的隔离区。

### 「你的游戏版本比本模组旧」

游戏还没更新，但你下载的是适配新版游戏的模组包。

处理：**先把游戏更新到最新**，再运行 `install.bat`。

> 这种情况常出现在：游戏刚推更新不久，你下的是新包，但本地游戏还停在旧版本。

### 「游戏更新改动了本模组覆盖的 N 个资源包」

游戏更新**确实改到了这个模组覆盖的美术资源**。这种情况旧模组装上去会新旧混杂，只能等新版模组。

文档会列出具体是哪几个包变了。

> **注意区分**：如果版本号变了但提示的是「这次更新没有改动本模组覆盖的资源，可以正常安装」，那说明这次更新只是修 bug 之类，跟美术资源无关，直接装就行。

### 「有 N 个资源包在当前游戏里找不到」

游戏资源结构变了（大版本更新），需要新版模组。

### 「残留 N 个旧模组文件」

之前装的东西和本模组、和官方都对不上。

> **装过旧版模组不会被拦。** 程序能认出历史版本的模组文件，会提示「检测到 N 个文件来自旧版模组，将直接覆盖为新版」，直接装就行。

只有真正对不上任何已知版本的文件才会报这个。处理：
1. 运行 `uninstall.bat` 退回国服原版，然后再运行 `install.bat`
2. 或者用命令行自动还原：
   ```
   powershell -ExecutionPolicy Bypass -File tools\precheck.ps1 -AutoRepair
   ```

### 「没有备份目录可还原」

游戏目录里有被改过的文件，但没有备份可以退回去。

处理：用游戏平台（Steam / 官方启动器）的「验证文件完整性」功能修复，或者重新安装游戏。

### 「备份目录是旧版游戏留下的」

备份目录里的文件是旧版游戏的，版本对不上，不能用来还原。

处理：同上，用平台验证文件完整性。

### 「磁盘空间不足」

清理空间。替换过程需要约 1.1 GB 的临时空间。

### 「写入校验失败」

某个包写进去之后 md5 对不上。可能是：

- 杀毒软件实时扫描锁住了文件
- 硬盘有问题
- 权限不足

处理：先 `uninstall.bat` 退回去，关掉杀毒软件实时防护，再重装。

## 二、装完了但界面异常

### 一片白块 / 图标空白 / 商店图片不见了

**最常见的两个原因：**

1. **游戏更新过，模组是旧的** —— 先看版本对不对得上
2. **之前在 IR / PS 两层之间写错过** —— 用 `uninstall.bat` 彻底退回去再装

判断方法：看白块出现在哪类界面。

| 白块位置 | 可能原因 |
|---|---|
| 商店、物品、图标类 | icon 包处理出问题（层写错） |
| 角色立绘、卡图 | 对应角色包没装对 |
| 整个界面都白 | 相关 UI 包被误改 |

**注意**：如果是「本来就没有图」的位置（比如某些未实装内容），那不是 bug。

### 旅人列表 / 秘纹列表的卡图没变

卡图在 icon 包里。如果卡图没换而其他内容换了，说明 icon 包没装对。

检查 `data/manifest.tsv` 里 `icon-*` 那 16 行的「层」字段，应该是 `PS`。

### 某个角色立绘没换

看这个角色的包在清单里有没有：

- 立绘看 `char_2d_<id>`
- 剧情立绘看 `char_avg_2d_*`
- Live2D 看 `char_l2d_<id>`

不在清单里 = 这个角色本来就没被和谐，不需要换。

### 立绘遮罩异常（圣光 / 遮挡布）

日服 2.0.0 删掉了 `masktexture.asset` 这个资产，模组有 28 个 Live2D 包因此缺这个文件。

如果出现遮罩相关异常，这可能是原因。反馈时说明具体是哪个角色、什么现象。

### 界面文字变成日文

不应该发生。模组的替换范围里有排除本地化资源（`*_lang`、`Dictionary_*`、`tab_*_lang`）。

如果出现了，说明装错了包，反馈时说明具体界面。

## 三、卸载相关

### 「没找到任何备份目录」

备份目录被删了，或者当时不是用这个包装的。

处理：用平台验证文件完整性。

### 卸载后游戏还是不对

1. 确认游戏完全退出后卸载
2. 用平台验证文件完整性
3. 最坏情况重装游戏

---

## 四、反馈问题时请带上这些

能大幅加快定位：

1. **`tools\precheck.bat` 的完整输出**（截图或复制文字）
2. **`data/game_version.txt` 的内容**
3. **游戏 `Persistent_Store\ss_win.mani` 里 `$RES_VER` 那一行**
4. **具体是哪个界面、哪个角色、什么现象**
5. **是否之前装过旧版模组、是否中途更新过游戏**

第 5 点特别重要。「装过旧版没卸载就更新游戏」是效果不一致的头号原因。

---

## 五、一些常见误解

**「装了没反应」**
先跑 precheck。十有八九是版本对不上或旧模组残留。

**「上次能用这次不能」**
游戏更新了。检查 `RES_VER`。

**「别人能用我不能」**
环境不同。precheck 会说明你的环境哪里不一样。

**「重装了模组就行了吧」**
如果游戏目录本身已经是脏的（残留旧文件），光重装模组没用，要先退回国服原版。precheck 会拦住这种情况。
