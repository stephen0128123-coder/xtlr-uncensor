# 星塔旅人（国服）反和谐包 · 玩家使用说明 v1.1

---

## 这是什么

把国服《星塔旅人》里被和谐的立绘 / Live2D / 图标 / 抽卡图等美术资源，替换为日服原版（未和谐）。

**内容范围**：角色 Live2D 立绘、静态立绘、秘纹美术、头像图标、抽卡封面等。

**你不需要有日服游戏**——资源由安装器自动下载。

---

## 怎么安装

### 第 1 步：下载安装器

从发布页下载安装器压缩包（**只有几 MB**），解压到任意文件夹。

> 安装器本身不含资源。资源会在安装时自动下载（约 1.2 GB）。

### 第 2 步：退出游戏

**必须完全退出。** 打开任务管理器（Ctrl+Shift+Esc），确认没有 `xtlr.exe` 进程。

> 如果游戏或启动器还开着，文件会被占用，替换会失败。

### 第 3 步：双击 `install.bat`

程序会自动：

1. 从 GitHub 下载资源（约 1.2 GB，视网速 1~15 分钟）
   - 显示下载进度百分比
   - 内置多个下载通道，自动选最快的能用的
2. 自动搜索你的星塔旅人安装目录
   - 找到 → 直接开始替换
   - 没找到 → 提示你把游戏目录拖进窗口
3. 备份原文件 + 替换
4. 显示结果

### 第 4 步：进游戏

---

## 怎么退回原版

双击 `uninstall.bat`。

程序会自动找到备份，把文件还原成国服原版。

**备份位置**：
```
<游戏目录>\_uncensor_backup_<时间戳>\
```

> ⚠️ **请勿删除该备份目录**，否则无法退回原版。

> ✅ 可以放心反复运行 `install.bat`：它始终复用**第一次**创建的备份，不会用「已改过的文件」覆盖原始版本。

## 常见问题

**Q: 下载卡住 / 很慢怎么办**

安装器会自动切换通道（直连 → ghproxy.net → gh-proxy.com → ghfast.top）。

如果都不行：
- 检查是否有代理软件干扰（临时关掉试试）
- 挂个代理再试（有代理时会自动走代理）
- 手动下载发布页里的资源文件，放进 `data/full/`（保持压缩包解开后的目录结构），然后运行：
  ```
  powershell -ExecutionPolicy Bypass -File tools\install.ps1 -NoDownload
  ```

**Q: 提示「检测到游戏正在运行」**

完全退出游戏（含启动器）后重试。

**Q: 自动定位游戏目录失败**

手动把游戏目录拖进窗口。要选到**带 `xtlr.exe` 的那一层**，通常形如：
```
F:\Game\YostarGames\StellaSora_CN
```

**Q: 游戏更新后需要重做吗**

需要。游戏更新可能覆盖这些文件。届时**重新运行 `install.bat`** 即可——安装器会自动检测到新版本资源并下载。

**Q: 安装了好几次，还能退回原版吗**

能。安装程序始终复用第一次创建的备份。

**Q: 还原后仍有改动的迹象**

极少数资源包（如字体、语言相关图标）是**有意保留**国服版本的，换成日服会显示日文。属正常现象。

**Q: 会封号吗**

本包仅替换本地美术资源，不修改游戏程序，不影响联机，不触碰内存。风险自负，建议仅在个人设备上使用。
