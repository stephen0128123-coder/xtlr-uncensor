# 星塔旅人小开关（适配2026年11月13日更新）

国服 PC 美术资源替换包，适配 **2026年11月13日更新 / 游戏2.1.0**。上一版 v2.1.1 适配游戏2.0.2，不能混装。

**下载完整压缩包：[星塔旅人小开关（适配2026年11月13日更新）](https://github.com/stephen0128123-coder/xtlr-uncensor/releases/tag/update-2026-11-13)**。不要下载仓库的 Source code 代替完整包，仓库不含约1GB美术资源。

## 怎么用

1. 完整解压到**游戏目录外**，退出游戏和启动器正在执行的更新任务。
2. 双击 `install.bat`，自动找国服；找到多个目录时选编号，找不到才弹文件夹窗口。
3. 不用了，双击同一份包里的 `uninstall.bat`。

**游戏更新顺序：卸载小开关 → 更新游戏 → 安装适配新日期的小开关。** 已经更新过就不要用旧包卸载来覆盖新资源；先保留现场排查。名称中的日期只表示本包核对到的官方更新，不保证之后的其他热更自动兼容。

## 本次变化

- 适配游戏2.1.0，共132个资源：112个基础层、20个补丁层；不能拿旧版128包覆盖新版。
- 保留自动定位，修正重复记录、重复目录/哈希操作带来的卡顿；窗口会显示启动、准备及逐文件进度。
- 卸载只放回本次保存的原文件和原有时间、属性；不扫描其他资源、不做完整官方复验，也不重复检查。
- 备份、锁和记录全在游戏外的 `%LOCALAPPDATA%\XingtaSwitch\`；本包不在游戏根目录或资源层新建工具路径，不删除其他模组、用户内容或旧版目录。
- 卸载前别删备份和记录；备份缺失、文件占用、复制失败会报未完成。本版不自动识别已更新后的官方文件，也不检查备份是否被外部改坏。

安装前原文件通常就是官方文件；若原本有其他改动，卸载恢复的也是当次保存的原件，不能把未知初始内容称为官方干净状态。只需要国服，不需要日服。
