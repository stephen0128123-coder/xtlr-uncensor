## 安装

1. 完全退出游戏，把压缩包整个解压。
2. 双击 `install.bat`，**安装器会自动找国服目录**，正常情况下不需要拖入或填写路径。
3. 找到多个候选目录时按编号选择；自动找不到时才会弹出文件夹选择窗口。
4. 查看安装结果，再自行启动游戏检查效果。

`data`、`tools` 和两个 BAT 必须在同一层。发现的路径会显示在窗口中；如果有多个游戏副本或自定义深层目录，应核对路径，必要时选择正确目录。不要和其他来源的小开关混装。

安装器会先检查本包数据是否完整、游戏及目标资源是否适配，再备份现有文件并替换。**不再要求玩家当前资源必须等于某几个预设原件哈希。** 当前文件可能来自不同官方布局或曾被其他工具替换，备份只保证还原安装前字节，不代表它必然是官方原版。

## 卸载与游戏更新

- 双击同一解压文件夹的 `uninstall.bat`，同样自动定位游戏。
- 保留解压文件夹和游戏中的 `_xingta_switch` 备份/收据，不要删除。
- 本修订保留原 metadata/manifest 和包身份，原 v2.1.1 已有收据仍可识别。
- 更新游戏前先正常卸载，再更新；卸载仍会拒绝用旧备份覆盖更新后的未知资源。
- 不使用更旧 `_uncensor_backup_*` 的最早备份来覆盖新游戏，也不补写未列出的另一层。

如果原 v2.1.1 在安装前就报 icon-0 等原件哈希不允许并且提示未写入资源，可直接换本次完整包重试，不需要为这个误拦先重装游戏。

## 内容与本次修订

- 共128包：112基础层、16补丁层 icon；125份与v2.1.0相同，三个icon更新25张美术纹理。
- 本次只改安装流程，美术资源与此前 v2.1.1 完全相同。
- 自动定位参考旧版的注册表、常见安装路径和浅层搜索；找不到才手动选文件夹。
- 取消现有文件的作者样本白名单拦截；改为精确备份安装前原件，恢复时验证备份双哈希。
- 不因无关清单字段或 RES 变化直接拒绝；仍要求游戏版本和本包目标的官方清单MD5适配，避免旧包盖掉真正更新的内容。
