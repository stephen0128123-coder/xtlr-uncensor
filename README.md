# 星塔旅人（国服）反和谐包 · GitHub 分发版

把国服《星塔旅人》里被和谐的美术资源替换为日服原版。

**本仓库只存放资源的分发配置与安装器**，资源本体放在 [Releases](../../releases) 里。

---

## 给玩家

### 怎么用

1. 下载安装器（几 MB，不含资源）
2. 解压到任意目录
3. **完全退出游戏**（任务管理器确认没有 `xtlr.exe`）
4. 双击 `install.bat`
   - 安装器会自动从本仓库下载资源（约 1.2 GB）
   - 然后自动定位游戏目录并替换
5. 进游戏查看效果

### 怎么退回原版

双击 `uninstall.bat`，自动还原。

### 安装器为什么这么小

资源不随安装器分发，而是运行时从 Releases 下载。好处是：
- 安装器体积小、下载快
- **更新只需更新 Releases，安装器永远不用换**

### 下载慢 / 连不上怎么办

安装器内置多通道自动降级，会依次尝试：

1. GitHub 直连
2. `ghproxy.net` 镜像
3. `gh-proxy.com` 镜像
4. `ghfast.top` 镜像

理论上总有一个能通。如果全部失败：

- 检查是否有代理软件冲突
- 挂代理后重试（有代理时直连通道会自动走代理）
- 或手动下载 Releases 里的文件，放进 `data/full/`，然后用 `-NoDownload` 参数运行
