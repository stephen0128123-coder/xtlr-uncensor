# 星塔旅人（国服）反和谐包 v2.1.0

适配游戏版本 **2.0.1**（`RES_VER 2610291842`）。面向玩家的一键安装包，解压即用，不依赖网络。

> **这是什么**：把《星塔旅人》（Stella Sora，国服 PC 端，Yostar 启动器）里被和谐的角色立绘、卡图、Live2D 恢复成日服版本的资源包。只替换游戏目录下的 `.unity3d` 资源文件，不涉及内存修改或进程注入。

## 请照这个顺序做

### 安装

1. **完全退出游戏**
2. 把压缩包**整个解压**到一个文件夹
3. 双击里面的 `install.bat`
4. 看到「全部 128 个包写入成功」就装好了
5. 双击游戏目录里的 `xtlr.exe` 启动

> 不要双击压缩包里面的 install.bat，那样只会解出一部分文件。
> 判断对不对：`data` 文件夹要和 `install.bat` 在同一个目录。

### 游戏要更新的时候

**先卸载，再更新，再装回来。**

```
1. 双击 uninstall.bat        ← 先退回国服原版
2. 打开启动器，更新游戏
3. 再双击 install.bat        ← 装回小开关
```

**顺序不能反。** 先更新再卸载，会把备份里的旧文件盖到新版游戏上。

### 卸载

双击 `uninstall.bat`，会把备份的原版文件还原回去。

## 装完没效果 / 界面白块怎么办

**先判断白块出现在哪类界面：**

| 白块位置 | 原因 | 怎么办 |
|---|---|---|
| **新角色 / 新皮肤 / 新活动** | 模组版本落后，包里没有新素材 | 等新版模组 |
| 商店、物品、旅人列表 | icon 包层写错 | 卸载 → 完整修复 → 重装 |
| 角色立绘、卡图 | 对应角色包没装对 | 同上 |

**如果是老内容白块**，按这个流程修：

```
1. 双击 uninstall.bat
2. 打开星塔旅人启动器 → 点「完整修复」→ 等它跑完
3. 再双击 install.bat
```

### 彻底修不好

```
1. 卸载游戏
2. 把游戏根目录里的 StellaSora_CN 文件夹整个删掉（只删这一层）
3. 重新下载安装游戏
4. 再打这个包
```

### 安装包提示「这个文件夹不完整」

没解压全。右键压缩包 →「解压到当前文件夹」，再进解压出来的文件夹运行。

## 常见问题

**Q：会封号吗？**
不知道。这个包只替换游戏目录里的资源文件，不读写内存、不注入进程、不改可执行文件。但风险判断不在本仓库范围内。

**Q：有手机版吗？**
没有。只做了 PC 端。

**Q：能用在 B 服吗？**
没测试过。B 服资源结构可能不同。

**Q：装完文字变日文了吗？**
不应该。替换范围排除了本地化资源。如果出现，说明装错了包。

**Q：备份目录能删吗？**
**不能。** `_uncensor_backup_*` 删了就没法用 `uninstall.bat` 还原。

**Q：为什么有的角色没变？**
不在清单里 = 这个角色本来就没被和谐。

## 注意事项

- 备份目录 `_uncensor_backup_<时间戳>` **不要删**
- 装之前确认游戏已完全退出
- 只能在官方启动器版本上使用，别和别的小开关混装
