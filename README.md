# 星塔旅人（国服）反和谐包 v2.0

适配游戏版本 **2.0.0**。面向玩家的一键安装包，解压即用，不依赖网络。

## 下载

到 [Releases](../../releases/latest) 下载 `ssmod_v2.0.zip`（约 1.06 GB），解压后运行 `install.bat`。

- `https://ghfast.top/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v2.0.zip`

## 装之前请先看这段

**安装程序会先自动检查你的游戏环境，检查不通过就不会动任何文件。**

这样能拦住绝大多数「装了没效果 / 界面白块 / 卡图没换」的情况，常见原因有：

- 装过旧版模组没卸载，直接就更新游戏了
- 游戏更新了但还在用旧版模组包
- 上次装到一半中断，文件只改了一半
- 备份目录被删了，出问题没法还原

检查会告诉你具体是哪一条，并给出处理办法。

## 安装

1. **完全退出游戏**
2. 解压后双击 `install.bat`
3. 程序先跑环境检查
   - 显示「环境检查通过」才会继续安装
   - 报错就按提示处理，游戏文件不会被改动
4. 装完直接双击游戏目录里的 `xtlr.exe` 启动

## 如果检查报错怎么办

| 提示 | 怎么办 |
|---|---|
| 游戏正在运行 | 完全退出游戏（任务管理器里确认 xtlr.exe 没了）再装 |
| 资源版本不匹配 / 游戏版本不匹配 | 游戏更新过了，去下新版模组 |
| 残留旧模组文件，请先运行 uninstall.bat | 先运行 `uninstall.bat` 退回国服原版，再装 |
| 没有备份目录可还原 | 用游戏平台「验证文件完整性」或重新安装游戏 |
| 备份目录是旧版游戏留下的 | 备份过期了，用游戏平台验证文件完整性 |
| 磁盘空间不足 | 腾出空间再装 |

## 想省事？用自动还原

大多数「旧模组残留」的情况，可以让程序自己还原后再装。用命令行运行：

```
tools\precheck.bat
```

或者带自动修复参数：

```
powershell -ExecutionPolicy Bypass -File tools\precheck.ps1 -AutoRepair
```

还原完再双击 `install.bat` 即可。

## 卸载

双击 `uninstall.bat`，会退回国服原版。

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**，更新会覆盖模组文件
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**，删了就无法一键还原
- 备份目录里记着当时的游戏版本，游戏大版本更新后旧备份会失效（程序会提示）
