## 怎么用

### 第 1 步：解压

把下载的 zip **完整解压**到任意文件夹（**不要**直接在压缩包里双击运行）。

> 解压后应该能看到 `install.bat`、`uninstall.bat`、`data`、`tools` 这几项。
> 本包放在哪个盘、哪个文件夹都可以，不影响使用。

### 第 2 步：完全退出游戏

打开任务管理器（`Ctrl + Shift + Esc`），确认**没有** `xtlr.exe` 进程。

> 游戏或启动器还开着的话，文件会被占用，替换会失败。

### 第 3 步：双击 `install.bat`

程序会自动：

1. 搜索你的星塔旅人国服安装目录
   - 自动找到 → 直接开始替换
   - 没找到 → 提示你把游戏目录拖进窗口后回车
     （例如 `F:\Game\YostarGames\StellaSora_CN`）
2. 备份原文件
3. 替换为反和谐资源
4. 显示结果

### 第 4 步：进游戏

完成后直接进游戏查看效果。

## 怎么退回原版

双击 `uninstall.bat`，程序会自动找到备份并还原成国服原版。

**备份位置**（首次安装时自动创建）：

```
<游戏目录>\_uncensor_backup_<时间戳>\
```

> **请勿删除该备份目录**，否则无法退回原版。

> 可以放心反复运行 `install.bat`：它始终复用**第一次**创建的备份，
> 不会用「已经改过的文件」覆盖原始版本，所以任何时候都能干净退回原版。

## 常见问题

**Q: 提示「检测到游戏正在运行」？**

完全退出游戏（含启动器）后重试。

**Q: 自动定位游戏目录失败？**

手动把游戏目录拖进窗口。要选到**带 `xtlr.exe` 的那一层**，通常形如：

```
F:\Game\YostarGames\StellaSora_CN
```

**Q: 还原后仍有改动的迹象？**

极少数资源包（如字体、语言相关图标）是**有意保留**国服版本的，不属于和谐内容
（换成日服会显示日文）。属正常现象。

**Q: 游戏更新后需要重做吗？**

需要。游戏更新可能覆盖这些文件，届时**重新运行 `install.bat`** 即可
（如果不奏效，说明资源包也需更新，等新版发布）。

**Q: 安装了好几次，还能退回原版吗？**

能。安装程序始终复用第一次创建的备份，原始版本不会被覆盖。
