# 星塔旅人（国服）反和谐包 v2.0.1

适配游戏版本 **2.0.0**。面向玩家的一键安装包，解压即用，不依赖网络。

## 下载

到 [Releases](../../releases/latest) 下载 `ssmod_v2.0.1.zip`（约 1.09 GB），解压后运行 `install.bat`。

镜像下载（任选其一，直连不通时用）：

- `https://ghproxy.net/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v2.0.1.zip`
- `https://ghfast.top/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v2.0.1.zip`

## v2.0.1 更新内容

- 修复：部分角色在装过旧版后替换不生效的问题
- 修复：部分抽卡封面未生效的问题
- 改进：安装结束会报告成功数量，失败会列出具体文件
- 改进：检测到旧版残留时会自动清理，不需要你再手动卸载

## 装之前请先看这段

**安装程序会先自动检查你的游戏环境，检查不通过就不会动任何文件。**

如果检测到旧版模组残留，会自动用备份还原再继续装，不需要你手动操作。

## 安装

1. **完全退出游戏**
2. 解压后双击 `install.bat`
3. 程序先跑环境检查，通过后自动安装
4. 装完直接双击游戏目录里的 `xtlr.exe` 启动

## 装完怎么确认成功

看到这句就对了：

```
全部 131 个包写入成功
```

如果是「成功 X / 131 个包，失败 N 个」，说明有文件没写进去，按提示处理。

## 如果检查报错怎么办

| 提示 | 怎么办 |
|---|---|
| 游戏正在运行 | 完全退出游戏（任务管理器里确认 xtlr.exe 没了）再装 |
| 游戏版本比本模组旧 | 先把游戏更新到最新，再装 |
| 游戏更新改动了 N 个资源包 | 游戏改到了美术资源，等新版模组 |
| 残留文件无法还原 | 打开星塔旅人启动器，点「完整修复」，等它跑完再装 |
| 磁盘空间不足 | 腾出空间再装 |

## 最后一招

上面全都不行的话：

1. 卸载游戏
2. 把游戏根目录里的 `StellaSora_CN` 文件夹**整个删掉**（只删这一层，别删它的上级目录）
3. 重新下载安装游戏
4. 再打这个包

## 卸载

双击 `uninstall.bat`，会退回国服原版。

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**，删了就无法一键还原
- 小更新（只修 bug 那种）不会让你重装，程序会自己判断
