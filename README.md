# 星塔旅人小开关（适配2026.11.14）更新

国服 PC 美术资源替换工具，适配 **2026年11月14日更新 / 游戏 2.1.0**。上一版 v2.1.1 适配游戏 2.0.2，两者不是同一批资源，**不要混装**。

**下载完整压缩包：[星塔旅人小开关（适配2026.11.14）更新](https://github.com/stephen0128123-coder/xtlr-uncensor/releases/tag/update-2026-11-14)**。不要下载仓库的 Source code 当完整包——仓库里没有约 1GB 的美术资源。

## 怎么用（窗口版，推荐）

1. 完整解压到**游戏目录外**，退出游戏和正在执行的启动器更新任务。
2. **右键 `星塔旅人小开关.exe` → 以管理员身份运行。** 必须用管理员身份，普通身份可能提示 `operation.lock` 访问被拒绝。
3. 等它自动找到国服目录（找到多个时自己挑一个，找不到点「选择目录」）。
4. 点「安装小开关」，等进度条走完，中间别关窗口。
5. 装完点「启动游戏」，直接进游戏。

不用了就在同一个窗口点「卸载 · 放回原文件」。

## 怎么用（命令行）

不想用窗口也可以：双击 `install.bat` 自动定位安装，`uninstall.bat` 放回原文件。两个入口操作同一套东西，不要同时开。

## 游戏更新顺序

**卸载小开关 → 更新游戏 → 安装适配新日期的版本。**

已经更新过游戏，就不要用旧包卸载去覆盖官方新文件，先保留现场排查。名称里的日期表示本包核对到的官方更新，不保证之后的其他热更自动兼容。

## 官方公告提醒

窗口版启动时会读一次星塔旅人国服官网的公告，**只弹**维护、更新、闪断、修复、版本、延期这一类；招募、活动说明、生日、直播、兑换码这些不弹。

- 「查看完整公告」只打开官网原文，公告窗口不会跟着关。
- 勾「下次更新前不再提示」后，直到官方发布更新的公告才会再打扰。
- 想随时看：窗口右上角有「**官方公告**」按钮，点开列出最近 5 条维护/更新类通知，点标题直接打开官网原文。
- 读不到（断网、官网改版）只在「查看操作详情」里记一行，不影响安装、卸载和启动。

## 备份在哪

备份、锁和记录全在 `%LOCALAPPDATA%\XingtaSwitch\`，不在游戏根目录留下工具路径，也不会删除其他模组、用户内容或旧版目录。

**卸载前别删备份和记录。** 备份缺失、文件占用、复制失败都会如实报未完成，此时不要更新游戏。
