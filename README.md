# 星塔旅人（国服）反和谐包 v2.0

适配游戏版本 **2.0.0**。面向玩家的一键安装包，解压即用，不依赖网络。

## 下载

到 [Releases](../../releases/latest) 下载 `ssmod_v2.0.zip`（约 1.06 GB），解压后运行 `install.bat`。

镜像下载（任选其一，直连不通时用）：

- `https://ghproxy.net/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v2.0.zip`
- `https://ghfast.top/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v2.0.zip`

## v2.0 更新内容

- 修复：部分界面图标与图片显示异常
- 补充：旅人列表与秘纹列表的卡图
- 重新适配 2.0.0 的角色、剧情立绘与秘纹卡图

## 安装

1. 完全退出游戏
2. 解压后双击 `install.bat`
3. 按提示确认游戏目录（一般会自动找到）
4. 装完直接双击游戏目录里的 `xtlr.exe` 启动

卸载：双击 `uninstall.bat`。

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**
- 装之前请确认游戏已完全退出
