## 安装：解压 → 运行 → 选目录

1. 完全退出游戏。
2. 把安装包整个解压到独立文件夹，不要在压缩包内双击脚本。
3. 双击 `install.bat`，将**国服游戏目录**拖入窗口后按回车。该目录应包含 `xtlr.exe`。
4. 看到全部 128 个包写入成功后，再自行启动游戏，检查原先出现白块的界面。

`data`、`tools` 必须与 `install.bat` 在同一层。没有安装过小开关时可直接安装；仍有旧版生效时，应先用原版本卸载。不要混装不同来源的包。

## 卸载与游戏更新

- 卸载：双击**本次安装使用的同一个文件夹**中的 `uninstall.bat`。
- 游戏更新前：先卸载小开关，再更新；更新后核对是否有适配的新版本，不要盲装旧包。
- 备份和收据位于游戏目录的 `_xingta_switch` 中，**不要删除**。保留原解压文件夹，恢复时需要它的清单和元数据。
- 本版不复用旧 `_uncensor_backup_*` 备份，也不会用旧备份覆盖更新后的未知文件。基准变化或收据损坏时会停止，请保留现状并看[故障排查](docs/TROUBLESHOOTING.md)。
