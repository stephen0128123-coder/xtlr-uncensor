# 星塔旅人小开关（适配2026.11.27）更新

[下载完整分享包](https://github.com/stephen0128123-coder/xtlr-uncensor/releases/tag/update-2026-11-27)。请选择 Releases 中的 ZIP 附件，不要下载 Source code；仓库源码不含完整美术资源。

## 使用方法

适用：国服 Windows PC，游戏 2.1.1，适配 2026.11.27 更新。日服仅用于对照美术，不是安装目标。

1. 把完整 ZIP 解压到游戏目录外，退出游戏并等启动器更新结束。
2. 右键「星塔旅人小开关.exe」→「以管理员身份运行」，确认自动找到的是自己的国服目录。
3. 点「安装小开关」，等进度完成；想进游戏时再点「启动游戏」。右上角「官方公告」可查看近期维护和更新提醒。
4. 卸载用同一份包里的「卸载 · 放回原文件」。备份和记录在 %LOCALAPPDATA%\XingtaSwitch，不要提前删除。

必须先卸载小开关，再更新游戏。如果带着旧开关完成了热更，不要用旧包卸载，也不要叠装新版，先保留备份与记录排查。

命令行入口 `install.bat` / `uninstall.bat` 仍保留，不要与窗口同时操作。
