# 星塔旅人（国服）反和谐包 v3.0

适配游戏版本 **2.0.0**。面向玩家的一键安装包，解压即用，不依赖网络。

## 下载

到 [Releases](../../releases/latest) 下载 `ssmod_v3.0.zip`（约 500 MB），解压后运行 `install.bat`。

镜像下载（任选其一，直连不通时用）：

- `https://ghproxy.net/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v3.0.zip`
- `https://ghfast.top/https://github.com/stephen0128123-coder/xtlr-uncensor/releases/latest/download/ssmod_v3.0.zip`

## v3.0 更新内容

- 修复：部分界面图标显示异常
- 修复：部分界面图片显示异常
- 修复：部分抽卡封面显示异常

## 安装

1. 完全退出游戏
2. 解压后双击 `install.bat`
3. 按提示确认游戏目录（一般会自动找到）
4. 装完直接双击游戏目录里的 `xtlr.exe` 启动

卸载：双击 `uninstall.bat`。

## 常见问题

**Q：更新游戏后失效了？**
A：游戏更新会覆盖模组文件，重新运行一次 `install.bat` 即可。

**Q：装完立绘空白 / 不显示？**
A：先 `uninstall.bat` 退回国服原版，再重新 `install.bat`。仍不行请反馈。

**Q：备份目录能删吗？**
A：不能。`_uncensor_backup_<时间戳>` 里存的是国服原版文件，删了就无法一键还原。
