# 星塔旅人（国服）反和谐包 v2.0

> 适配游戏 **2.0.0**。国服 2.0.0 大更新后资源几乎全部重打，本版为 2.0.0 重新构建。

## v2.0 更新内容

- 修复：部分界面图标与图片显示异常
- 补充：旅人列表与秘纹列表的卡图
- 重新适配 2.0.0 的角色、剧情立绘与秘纹卡图

## 怎么用

1. **完全退出游戏**
2. 双击 `install.bat`
3. 按提示确认游戏目录（一般会自动找到），等它跑完
4. 启动游戏（直接双击 `xtlr.exe`，不要走启动器）

卸载：双击 `uninstall.bat`，会退回国服原版。

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**，更新会覆盖模组文件
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**，删了就无法一键还原
- 装之前请确认游戏已完全退出，否则文件会写入失败

## 内容说明

共 128 个资源包，涵盖：

- 角色卡图与皮肤卡图
- 角色静态立绘与剧情立绘
- 秘纹卡图
- 角色 / NPC Live2D
