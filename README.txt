# 星塔旅人（国服）反和谐包 v2.0

> 适配游戏 **2.0.0**。国服 2.0.0 大更新后资源几乎全部重打，v1.1 已失效，本版为 2.0.0 重新构建。

## v2.0 更新内容

- 修复：v1.1 在 2.0.0 版本下不生效的问题
- 修复：部分角色与 NPC 立绘显示异常
- 重新适配 2.0.0 新增的角色美术资源

## 怎么用

1. **完全退出游戏**
2. 双击 `install.bat`
3. 按提示确认游戏目录（一般会自动找到），等它跑完
4. 启动游戏（直接双击 `xtlr.exe`，不要走启动器）

卸载：双击 `uninstall.bat`，会退回国服原版。

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**，更新会覆盖模组文件
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**，删了就无法一键还原
- 装之前请确认游戏已完全退出，否则文件会写入失败

## 内容说明

共 128 个资源包，涵盖：

- 角色 / NPC 立绘与 Live2D
- 剧情立绘
- 秘纹（disc）
- 图标与头像
