星塔旅人小开关（适配2026.11.14）更新

适用：国服PC，游戏2.1.0。
用法一（推荐）：完整解压到游戏目录外，退出游戏，右键 星塔旅人小开关.exe → 以管理员身份运行。
　选好国服目录 → 点「安装小开关」，等进度走完 → 点「启动游戏」。
用法二（命令行）：双击 install.bat 自动定位安装；卸载用同一包的 uninstall.bat，直接放回本次保存的原文件。
必须以管理员身份运行；普通身份可能提示 operation.lock 权限不足。
启动时会弹一次官方公告（只提醒维护、更新这类），可以勾「下次更新前不再提示」。
想随时看：窗口右上角点「官方公告」，能看最近几条，点标题跳官网原文。
备份与记录在 %LOCALAPPDATA%\XingtaSwitch\，卸载前不要删除。
必须先卸载小开关，再更新游戏；已更新后不要用旧包卸载覆盖新文件。
本版资源与上一版逐字节相同（132 项），只新增窗口界面与公告提醒。
详细说明见 README.md，下载和更新记录：
