# 星塔旅人（国服）反和谐包 v2.0.2

适配游戏版本 **2.0.0**。面向玩家的一键安装包，解压即用。

---

## 请照这个顺序做

### 安装

1. **完全退出游戏**
2. 把压缩包**整个解压**到一个文件夹
3. 双击里面的 `install.bat`
4. 看到「全部 131 个包写入成功」就装好了
5. 双击游戏目录里的 `xtlr.exe` 启动

> 不要双击压缩包里面的 install.bat，那样只会解出一部分文件。
> 判断对不对：`data` 文件夹要和 `install.bat` 在同一个目录。

### 游戏要更新的时候

**先卸载，再更新，再装回来。**

```
1. 双击 uninstall.bat        ← 先退回国服原版
2. 打开启动器，更新游戏
3. 再双击 install.bat        ← 装回小开关
```

**顺序不能反。​** 先更新再卸载，会让备份里的旧文件盖到新版游戏上，问题更多。​

### 卸载

双击 `uninstall.bat`，会把备份的原版文件还原回去。​

---

## 其他情况怎么办

### 装完发现没效果 / 界面白块

先卸载，再用启动器的「完整修复」：

```
1. 双击 uninstall.bat
2. 打开星塔旅人启动器 → 点「完整修复」→ 等它跑完
3. 再双击 install.bat
```

### 卸载报「没找到备份目录」

说明之前没用这个包装过，或者备份目录被删了。​用启动器的「完整修复」代替。​

### 彻底修不好

```
1. 卸载游戏
2. 把游戏根目录里的 StellaSora_CN 文件夹整个删掉（只删这一层）
3. 重新下载安装游戏
4. 再打这个包
```

### 安装包提示「这个文件夹不完整」

没解压全。​右键压缩包 →「解压到当前文件夹」，再进解压出来的文件夹运行。​
