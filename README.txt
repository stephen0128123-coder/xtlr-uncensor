# 星塔旅人（国服）反和谐包 v2.0.1

> 适配游戏 **2.0.0**。面向玩家的一键安装包，解压即用。

## v2.0.1 更新内容

- 修复：部分角色在装过旧版后替换不生效的问题
- 修复：部分抽卡封面未生效的问题
- 改进：安装结束会报告成功数量，失败会列出具体文件
- 改进：检测到旧版残留时会自动清理，不需要再手动卸载

## 装之前请先看

**安装程序会先检查游戏环境，不通过就不动任何文件。**

检测到旧版模组残留会自己用备份还原，不需要你手动操作。

## 怎么用

1. **完全退出游戏**
2. 双击 `install.bat`
3. 程序先检查环境，通过后自动安装
4. 装完双击游戏目录里的 `xtlr.exe` 启动

卸载：双击 `uninstall.bat`，会退回国服原版。

## 装完怎么确认成功

看到这句就对了：

```
全部 131 个包写入成功
```

如果是「成功 X / 131 个包，失败 N 个」，说明有文件没写进去。

## 检查报错怎么办

| 提示 | 怎么办 |
|---|---|
| 游戏正在运行 | 完全退出游戏再装 |
| 游戏版本比本模组旧 | 先把游戏更新到最新 |
| 游戏更新改动了 N 个资源包 | 等新版模组 |
| 残留文件无法还原 | 启动器点「完整修复」再装 |
| 磁盘空间不足 | 腾出空间再装 |

## 最后一招

全都不行的话：

1. 卸载游戏
2. 把游戏根目录里的 `StellaSora_CN` 文件夹整个删掉（只删这一层）
3. 重新安装游戏
4. 再打这个包

## 遇到问题先看

- `docs\TROUBLESHOOTING.md` —— 各种报错怎么处理
- `docs\资源结构说明.md` —— 模组改了什么、为什么这么改

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**
- 小更新（只修 bug 那种）不会让你重装，程序会自己判断
