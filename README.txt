# 星塔旅人（国服）反和谐包 v2.1.0

> 适配游戏 **2.0.1**（RES_VER 2610291842）。一键安装，解压即用。

## 请照这个顺序做

### 安装

1. **完全退出游戏**
2. 把压缩包**整个解压**到一个文件夹
3. 双击里面的 `install.bat`
4. 看到「全部 128 个包写入成功」就装好了
5. 双击游戏目录里的 `xtlr.exe` 启动

> 不要双击压缩包里面的 install.bat，那样只会解出一部分。
> 判断对不对：`data` 文件夹要和 `install.bat` 在同一层。

### 游戏要更新的时候

**先卸载，再更新，再装回来。**

```
1. 双击 uninstall.bat        ← 先退回国服原版
2. 打开启动器，更新游戏
3. 再双击 install.bat        ← 装回小开关
```

顺序不能反。

### 卸载

双击 `uninstall.bat`，会把备份的原版文件还原回去。

## 装完没效果 / 白块

**先看白块出现在哪：**

| 白块位置 | 原因 | 怎么办 |
|---|---|---|
| 新角色 / 新皮肤 / 新活动 | 模组版本落后 | 等新版模组 |
| 商店、物品、旅人列表 | icon 包层写错 | 卸载 → 完整修复 → 重装 |
| 角色立绘、卡图 | 对应角色包没装对 | 同上 |

**老内容白块的修法：**

```
1. 双击 uninstall.bat
2. 启动器 →「完整修复」→ 等它跑完
3. 双击 install.bat
```

**彻底修不好：**

1. 卸载游戏
2. 把游戏根目录里的 `StellaSora_CN` 文件夹整个删掉（只删这一层）
3. 重新安装游戏
4. 再打这个包
