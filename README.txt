============================================================
  星塔旅人（国服）· 模组  v1.0
============================================================

【这是什么】
  把国服《星塔旅人》里被和谐的立绘 / Live2D / 图标 / 抽卡图等
  美术资源，替换为日服原版版本。

  内容范围：132 个资源包（1.2 GB）
    · 角色 Live2D 立绘（含说话动作、表情）
    · 角色静态立绘 / AVG 立绘差分
    · 秘纹（光碟）相关美术
    · 角色头像 / 服装图标
    · 抽卡封面（秘纹池 / 卡池）

  ★ 本包已内置全部替换文件，【不需要】你有日服游戏。


【使用方法】
  1. 先【完全退出游戏】（任务管理器里确认没有 xtlr.exe）
  2. 双击  install.bat
  3. 程序会自动搜索你的星塔旅人国服安装目录
       · 若自动找到 → 直接开始替换
       · 若没找到   → 会提示你把游戏目录拖进窗口后回车
         例如  F:\Game\YostarGames\StellaSora_CN
  4. 完成后进游戏查看效果

  ★ 本包放在哪个文件夹都可以，不影响使用。


【如何恢复原样】
  双击  uninstall.bat
  程序会自动找到安装时的备份，把文件还原成国服原版。

  备份位置：首次安装时自动创建
    游戏安装目录下、形如 _uncensor_backup_20261009_010457 的文件夹
  （如游戏目录不可写，则创建在本包目录下）

  ★ 可以放心反复运行 install.bat：
    它始终复用【第一次】创建的备份目录，不会用「已改过的文件」
    覆盖掉原始版本，因此任何时候都能干净恢复。
  ★ 请勿删除该备份目录，否则无法恢复。


【常见问题】
  Q: 提示「检测到游戏正在运行」？
  A: 请完全退出游戏（含启动器）后重试。

  Q: 自动定位失败？
  A: 手动把游戏目录拖进窗口。注意要选到带 xtlr.exe 的那一层，
     通常形如  ...\YostarGames\StellaSora_CN

  Q: 恢复后仍有改动的迹象？
  A: 极少数资源包（如字体、语言相关图标）是【有意保留】国服版本的，
     换成日服会显示日文。属正常现象。

  Q: 游戏更新后需要重做吗？
  A: 需要。游戏更新可能覆盖这些文件，届时重新运行 install.bat 即可。

  Q: 安装了好几次，还能恢复原样吗？
  A: 能。安装程序始终复用第一次创建的备份，原始版本不会被覆盖。


【注意事项】
  · 请先退出游戏再操作，否则文件会写入失败。
  · 建议安装前自行备份一次游戏目录（保险起见）。
  · 本包仅替换本地美术资源，不修改游戏程序，不影响联机。
  · 请自行评估使用风险；建议仅在个人设备上用于本地化体验。
