# 星塔旅人（国服）反和谐包 v2.0

> 适配游戏 **2.0.0**。国服 2.0.0 大更新后资源几乎全部重打，本版为 2.0.0 重新构建。

## v2.0 更新内容

- 修复：部分界面图标与图片显示异常
- 补充：旅人列表与秘纹列表的卡图
- 重新适配 2.0.0 的角色、剧情立绘与秘纹卡图

## 装之前请先看

**安装程序会先检查你的游戏环境，不通过就不动任何文件。**

这样能拦住绝大多数「装了没效果 / 界面白块 / 卡图没换」的情况，
比如装过旧版没卸载就更新游戏、游戏更新了还在用旧包、上次装到一半中断等。

## 怎么用

1. **完全退出游戏**
2. 双击 `install.bat`
3. 先跑环境检查，显示「环境检查通过」才会继续装
4. 装完双击游戏目录里的 `xtlr.exe` 启动（不要走启动器）

卸载：双击 `uninstall.bat`，会退回国服原版。

## 检查报错怎么办

| 提示 | 怎么办 |
|---|---|
| 游戏正在运行 | 完全退出游戏再装 |
| 版本不匹配 | 游戏更新了，去下新版模组 |
| 残留旧模组文件 | 先运行 `uninstall.bat` 还原 |
| 没有备份目录 / 备份过期 | 用游戏平台「验证文件完整性」或重装游戏 |
| 磁盘空间不足 | 腾出空间再装 |

## 注意事项

- **游戏更新后需要重新运行 `install.bat`**
- 备份目录 `_uncensor_backup_<时间戳>` **不要删**
- 装之前请确认游戏已完全退出

## 内容说明

共 128 个资源包，涵盖：

- 角色卡图与皮肤卡图
- 角色静态立绘与剧情立绘
- 秘纹卡图
- 角色 / NPC Live2D
